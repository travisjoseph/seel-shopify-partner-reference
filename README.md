# Seel Shopify Partner Integration - Reference Implementation

A reference implementation for partners who embed Seel Worry-Free Delivery in their own Shopify app. It covers the storefront widget (a theme app extension) and the partner backend that talks to Seel's Shopify API (`/v1/shopify/*`).

For partners on the direct `/v1/ecommerce/*` API, see [seel-direct-integration-reference](https://github.com/travisjoseph/seel-direct-integration-reference).

Work in progress.
